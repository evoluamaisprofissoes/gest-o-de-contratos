# Gestão de Contratos — Evolua+ Academy

Versão atual com processamento 100% local no navegador. Nenhum dado dos formulários é enviado ou armazenado pelo projeto.

## Modelos
- Contrato Presencial
- Contrato Evolua+ Academy
- Termo de Acesso Gratuito — 7 dias
- Contrato de Intermediação EJA EAD, com escolha entre MT-Cursos e CEC Educacional
- Termo de Rescisão de Contrato
- Aditivo de Trancamento de Aulas
- Termo de Compromisso de Bolsa / Condição Comercial

## Automatizações
- Datas de encerramento, vigência e retorno calculadas conforme cada modelo.
- Valores finais e parcelas da bolsa calculados automaticamente.
- Valor por extenso aproveitado nos documentos que já possuíam essa lógica.
- Dados da instituição EJA entram automaticamente conforme a instituição selecionada.
- Suporte a 1 ou 2 alunos no contrato EJA.
